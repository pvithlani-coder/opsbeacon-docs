## Reports

```
@Beacon run security economics report
@Beacon run AI economics report
@Beacon run the monthly cloud economics report
@Beacon give me the executive brief
@Beacon show me the FinOps scorecard
@Beacon what's my FinOps score?
```

## Cost analysis

```
@Beacon what's my AWS spend this month?
@Beacon show me spend by service for last week
@Beacon which AWS accounts are driving the most cost?
@Beacon break down my EC2 costs by region
@Beacon what will my AWS bill be this month?
@Beacon am I on track to hit my budget?
@Beacon any cost anomalies this week?
@Beacon what drove the cost spike yesterday?
@Beacon what are my top savings opportunities?
```

## AI economics

```
@Beacon show me AI spend by project
@Beacon which model is costing the most this month?
@Beacon what's the AI efficiency score for [project]?
@Beacon where is AI spend being wasted?
@Beacon show me AI ROI for Q3
```

## Security

```
@Beacon show me my security gaps
@Beacon what are the top 5 most expensive security findings?
@Beacon review finding-01
@Beacon tell me more about finding-02
```

## Findings & actions

```
@Beacon assign finding-01 to @alice
@Beacon mark finding-01 as resolved
@Beacon verify finding-01 now
@Beacon acknowledge finding-04
@Beacon what findings does @alice own?
@Beacon show me all open findings
@Beacon how much have we saved this quarter?
```

## Scheduling

```
@Beacon post the cost summary here every Monday at 9am
@Beacon run a FinOps standup here every weekday at 9am
@Beacon what reports are scheduled?
@Beacon cancel the weekly cost summary
```

## Alerts

```
@Beacon alert me when monthly spend exceeds $15,000
@Beacon alert me when a new critical security finding is detected
@Beacon what alerts are configured?
@Beacon remove the EC2 spend alert
```

## Configuration

```
@Beacon show me workspace settings
@Beacon set engineering hourly rate to $150
@Beacon change the reporting channel to #cloud-costs
```
