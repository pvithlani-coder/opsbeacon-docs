## October 2026

### New features
- **AI Economics Report** — project-level token spend tracking with efficiency scoring and waste detection
- **Security Economics Report** — security findings quantified in dollars with remediation cost per finding
- **FinOps Health Score** — composite score across cost optimization, AI efficiency, and security investment
- **Finding assignment** — assign security and cost findings to team members and track to resolution
- **Verified savings** — track whether resolved findings actually reduced your AWS bill

### Improvements
- Security finding deduplication by service — GuardDuty findings with similar descriptions now correctly consolidated
- Improved root cause analysis for EC2 cost spikes
