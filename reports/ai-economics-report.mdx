## What it covers

The AI Economics Report is the most comprehensive view of your AI spending:

- Total AI API spend for the period
- Spend and efficiency score by project
- Spend by model across all providers
- Unit economics (cost per 1K tokens, cost per API call)
- Waste analysis with specific optimization recommendations
- Month-over-month trend

## How to trigger it

```
@Beacon run the AI economics report
@Beacon show me AI spending this month
```
