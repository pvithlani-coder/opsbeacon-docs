## What it covers

The Cloud Economics Monthly Report gives a full picture of your AWS spend for the month:

- Month-over-month spend change with top movers
- Cost anomalies detected and resolved
- Savings recommendations with estimated value
- RI and Savings Plan utilization
- Month-end projection vs budget

## How to trigger it

```
@Beacon run the monthly cloud economics report
@Beacon give me the monthly cost summary
```

## Scheduling

```
@Beacon post the cloud economics report on the 1st of every month
```
