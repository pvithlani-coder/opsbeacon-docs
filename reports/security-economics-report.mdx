## What it covers

The Security Economics Report translates every open security finding into a monthly dollar cost — the financial exposure of leaving it unresolved. Findings are ranked by cost so you work on what matters most financially.

## How to trigger it

```
@Beacon run the security economics report
@Beacon show me security findings in dollar terms
```
