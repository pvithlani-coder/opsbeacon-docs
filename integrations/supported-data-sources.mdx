## Currently supported

| Source | Data type | Status |
|--------|-----------|--------|
| AWS Cost Explorer | Cost and usage data | ✅ Available |
| AWS Trusted Advisor | Savings recommendations | ✅ Available |
| AWS GuardDuty | Threat detection findings | ✅ Available |
| AWS Security Hub | Aggregated security findings | ✅ Available |
| AWS Bedrock | AI token usage | ✅ Available |
