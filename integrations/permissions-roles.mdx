## Role types

| Role | What they can do |
|------|-----------------|
| **Admin** | Full access — configure integrations, manage users, view all reports |
| **Analyst** | Run reports, view findings, assign actions |
| **Viewer** | View reports and findings only, cannot assign or configure |

## Default behavior

By default, anyone in your Slack workspace who can mention `@Beacon` can run reports and view findings. Role restrictions are optional.

## Restricting access

To restrict who can run certain reports:

```
@Beacon restrict the executive brief to Admins only
@Beacon who has admin access?
```

## Adding admins

Contact OpsBeacon support to add or remove admin users.
