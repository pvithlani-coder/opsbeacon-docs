## Start with the quick wins

Beacon surfaces the highest-ROI improvement actions each time you check your score:

```
@Beacon what would improve my FinOps score the most?
@Beacon show me the top 5 score improvement actions
```

## Cost Optimization improvements

- **Resolve idle resource findings** from Trusted Advisor — each resolved finding improves your waste ratio
- **Increase RI coverage** — identify on-demand usage that could be committed to
- **Improve tagging coverage** — tag untagged resources to improve cost attribution

## AI Economics improvements

- **Enable prompt caching** for workloads that send repeated or similar prompts
- **Rightsize model usage** — move classification or extraction tasks to smaller, cheaper models
- **Fix high retry rates** — investigate workloads with error rates above 5%

## Security Investment improvements

- **Resolve high-exposure, low-effort findings first** — best ratio of score impact to time spent
- **Enable GuardDuty** if not already active — its absence reduces the Security dimension score
- **Enable Security Hub** for centralized finding aggregation
