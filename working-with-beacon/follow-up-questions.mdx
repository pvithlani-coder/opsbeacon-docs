---
title: Follow-up Questions & Explanations
description: Beacon maintains context across a conversation so you can ask follow-ups naturally.
---

## How context works

Within a Slack thread or a session, Beacon remembers what you've been discussing. You don't have to repeat yourself:

```
@Beacon run the security economics report

[Beacon posts the report]

@Beacon tell me more about the top finding
@Beacon what would it cost to fix that?
@Beacon who should own that?
```

## Asking for explanations

If any output isn't clear, just ask:

```
@Beacon what does the security trade-off score actually mean?
@Beacon explain the AI efficiency score
@Beacon what's an RI and why does coverage matter?
```

## Starting fresh

If you want Beacon to start a new context rather than continuing a thread:

```
@Beacon new session — what are my top 3 priorities today?
```
