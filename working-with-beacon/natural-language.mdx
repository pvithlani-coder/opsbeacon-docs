## How it works

Beacon is built on a natural language understanding layer — you can ask it questions the same way you'd ask a colleague. It maps your request to the right report, analysis, or action.

## Examples

**Cost questions**
```
@Beacon what did we spend on AWS last month?
@Beacon why did my bill go up this week?
@Beacon which team is spending the most on EC2?
```

**Security questions**
```
@Beacon do we have any critical security findings?
@Beacon how much is our biggest security risk costing us?
@Beacon what would it take to fix our top 3 security gaps?
```

**AI economics questions**
```
@Beacon which AI project is the least efficient?
@Beacon how much are we spending on GPT-4 vs Claude?
@Beacon where are we wasting money on AI?
```

**Scoring and benchmarking**
```
@Beacon how does our FinOps score compare to similar companies?
@Beacon what would move our score the most right now?
```

## When Beacon doesn't understand

If Beacon isn't sure what you're asking, it will say so and ask for clarification. You can always rephrase or use a specific command from the [Commands Reference](/reference/command-reference).
